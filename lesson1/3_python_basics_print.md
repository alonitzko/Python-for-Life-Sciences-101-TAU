## 1. הפקודה `print()`

הפקודה `print()` משמשת להצגת מידע, הודעות ותוצאות חישוב בחלונית הפלט:

```python
print(123)
print("שלום עולם!")
print("ברוכים הבאים לקורס פייתון של אוניברסיטת תל אביב")
```

**פלט:**
```text
123
שלום עולם!
ברוכים הבאים לקורס פייתון של אוניברסיטת תל אביב
```

### הדפסת מספר ערכים יחד עם פסיק
ניתן להעביר לפקודה `print()` מספר ערכים מופרדים בפסיקים. פייתון תדפיס אותם בזה אחר זה כשהם מופרדים ברווח בודד:

```python
print("התוצאה של 5 ועוד 7 היא:", 5 + 7)
print("שם:", "מאיה", "גיל:", 21, "עיר:", "תל אביב")
```

**פלט:**
```text
התוצאה של 5 ועוד 7 היא: 12
שם: מאיה גיל: 21 עיר: תל אביב
```

## 2. הערות בקוד (`#`)

הערות הן טקסט שנכתב בתוך הקוד ומיועד לקורא האנושי בלבד. פייתון מתעלמת לחלוטין מכל מה שנכתב מימין לסימן הסולמית (`#`):

```python
# זוהי הערה בשורה נפרדת - מסבירה את מטרת התוכנית
print("קוד זה ירוץ")

print("גם זה ירוץ")  # הערה בסוף שורת קוד - מסבירה את הפקודה הספציפית
```

::{tip} מדוע הערות חיוניות?
כאשר תכתבו תוכנית של מאות שורות ותחזרו אליה בעוד חודשיים, לא תזכרו מדוע כתבתם שורה מסוימת. הערות ברורות חוסכות שעות של בלבול ומאפשרות לעבוד בצוות ביעילות!
:::
