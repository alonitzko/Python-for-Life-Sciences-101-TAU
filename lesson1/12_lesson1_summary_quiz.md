### שאלה 1 (מעקב פעולות חשבון וטיפוסים)
מה ערכו והטיפוס של `result`?
```python
result = 15 // 4 + 10 % 3 * 2.0
```

<details>
<summary><b>לחצו לצפייה בפתרון המלא</b></summary>

* **ערך:** `5.0`
* **טיפוס:** `float`
* **הסבר:**
  1. `15 // 4 = 3` (`int`).
  2. `10 % 3 = 1` (`int`).
  3. `1 * 2.0 = 2.0` (`float`).
  4. `3 + 2.0 = 5.0` (`float`).
</details>

### שאלה 2 (שרשור מחרוזות)
מה יודפס בסיום הרצת הקוד הבא?
```python
s = "A"
s = s + "B" * 2
print(s)
```

<details>
<summary><b>לחצו לצפייה בפתרון</b></summary>

**פלט:** `ABB`  
**הסבר:** כפל קודם לחיבור: `"B" * 2` יוצר `"BB"`. לאחר מכן `"A" + "BB"` יוצר `"ABB"`.
</details>

---

### תרגיל מעשי עצמאי: פירוק מספר תלת-ספרתי
כתבו קוד המקבל מספר שלם תלת-ספרתי `n = 482` ומדפיס בנפרד את ספרת המאות, העשרות והאחדות שלו בעזרת אופרטורי `//` ו-`%`.

<details>
<summary><b>לחצו לצפייה בקוד הפתרון</b></summary>

```python
n = 482

hundreds = n // 100
tens = (n % 100) // 10
units = n % 10

print("מאות:", hundreds)  # 4
print("עשרות:", tens)      # 8
print("אחדות:", units)     # 2
```
</details>
