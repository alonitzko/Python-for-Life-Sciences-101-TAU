### שאלה 1 (מעקב לולאה)
מה יודפס בסיום הקוד הבא?
```python
total = 0
for i in range(1, 5):
    if i % 2 == 0:
        total += i
print(total)
```

<details>
<summary><b>לחצו לצפייה בפתרון המלא</b></summary>

**תשובה:** `6`  
**הסבר:** הטווח `range(1, 5)` כולל את המספרים: `1, 2, 3, 4`. המספרים הזוגיים ביניהם הם 2 ו-4. סכומם: $2 + 4 = 6$.
</details>

### תרגיל מעשי: מציאת איבר מקסימלי ללא פונקציית `max()`
כתבו פונקציה בשם `find_max(L)` המקבלת רשימת מספרים לא ריקה ומוצאת את האיבר המקסימלי בעזרת לולאת `for` ותנאי:

<details>
<summary><b>לחצו לצפייה בקוד הפתרון</b></summary>

```python
def find_max(L):
    current_max = L[0]
    for x in L:
        if x > current_max:
            current_max = x
    return current_max

print("מקסימום:", find_max([14, 88, 32, 95, 7]))  # 95
```
</details>
