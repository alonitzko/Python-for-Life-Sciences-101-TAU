# שיעור 6: איורים ותרשימים גרפיים (Data Visualization)

![תרשימים גרפיים](../images/q07q05_02.jpg)

> **"תמונה אחת שווה אלף מילים; גרף אחד שווה עשרת אלפים שורות בטבלת נתונים."**

בעולם שבו מוצפים בנתונים, היכולת להמחיש ממצאים בתרשימים ברורים היא מיומנות קריטית לכל מדען, מהנדס ומפתח.  
בשיעור זה נכיר את ספריית התרשימים הסטנדרטית של פייתון: **`matplotlib.pyplot`**.
