### שאלה 1: טיפוסים ופעולות חשבון
מה יהיה הטיפוס והערך של המשתנה `res` לאחר הרצת השורה הבאה?
```python
res = (17 // 5) + (17 % 5) * 2.0
```

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

* **ערך:** `7.0`
* **טיפוס:** `float`
* **הסבר מפורט:**
  1. `17 // 5` הוא החלק השלם של החלוקה = `3` (`int`).
  2. `17 % 5` הוא שארית החלוקה = `2` (`int`).
  3. `2 * 2.0 = 4.0` (בגלל שהכפל הוא במספר עשרוני, התוצאה מומרת ל-`float`).
  4. `3 + 4.0 = 7.0` (חיבור בין שלם לעשרוני מניב תמיד `float`).
</details>

### שאלה 2: מחרוזות ואינדקסים
נתונה המחרוזת הבאה:
```python
s = "CampusIL_Python"
```
איזה מהביטויים הבאים יחזיר `True`?
* א. `s[0] == "c"`
* ב. `len(s) == 14`
* ג. `s[8] == "_"`
* ד. `"il" in s`

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

* **תשובה נכונה:** **ג** (`s[8] == "_"`)
* **הסבר מפורט:**
  * א' שגוי: `s[0]` היא האות הגדולה `'C'`, ופייתון רגישה לאותיות גדולות/קטנות (`"C" != "c"`).
  * ב' שגוי: אורך המחרוזת הוא 15 תווים (`len(s) == 15`), שכן יש 8 תווים ב-"CampusIL", תו אחד של קו תחתון, ו-6 תווים ב-"Python".
  * ג' נכון: התווים באינדקסים הם:
    `C(0) a(1) m(2) p(3) u(4) s(5) I(6) L(7) _(8)`.
  * ד' שגוי: המחרוזת מכילה `"IL"` באותיות גדולות, ולא `"il"`.
</details>

### שאלה 3: רשימות ו-Mutability
מה יודפס בסיום הרצת קטע הקוד הבא?
```python
a = [1, 2, 3]
b = a
b[0] = 99
print(a)
```

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

* **פלט:** `[99, 2, 3]`
* **הסבר מפורט (עקרון ה-Aliasing בפייתון):**
  כאשר מציבים רשימה במשתנה חדש (`b = a`), פייתון **אינה יוצרת עותק חדש של הרשימה**, אלא גורמת לשני המשתנים להצביע על **אותה הרשימה בדיוק בזיכרון**!
  לכן, שינוי האיבר דרך `b` משפיע באופן מיידי גם על מה שנראה דרך המשתנה `a`.
  אם רוצים ליצור עותק נפרד ועצמאי, יש להשתמש בשיבוט: `b = a.copy()` או `b = a[:]`.
</details>

### שאלה 4: מעקב אחרי לולאה מקוננת
כמה פעמים יודפס הביטוי `"TAU"` במהלך הרצת הקוד הבא?
```python
for i in range(4):
    for j in range(i):
        print("TAU")
```

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

* **תשובה:** `6` פעמים
* **הסבר לפי איטרציות הלולאה החיצונית:**
  * כש-`i = 0`: הלולאה הפנימית היא `range(0)` – רצה **0** פעמים.
  * כש-`i = 1`: הלולאה הפנימית היא `range(1)` – רצה **1** פעם (`j = 0`).
  * כש-`i = 2`: הלולאה הפנימית היא `range(2)` – רצה **2** פעמים (`j = 0, 1`).
  * כש-`i = 3`: הלולאה הפנימית היא `range(3)` – רצה **3** פעמים (`j = 0, 1, 2`).
  * סה"כ הדפסות: $0 + 1 + 2 + 3 = 6$.
</details>

### שאלה 5: פונקציות והחזרת ערך
נתונה הפונקציה הבאה:
```python
def check_values(x, y):
    if x > y:
        return x - y
    print(y - x)

res = check_values(3, 8)
print("Result is:", res)
```
מה יהיה הפלט המדויק על המסך?

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

* **פלט:**
  ```text
  5
  Result is: None
  ```
* **הסבר מפורט:**
  1. בקריאה `check_values(3, 8)` מתקיים `x = 3`, `y = 8`.
  2. התנאי `x > y` הוא `False` (כי 3 אינו גדול מ-8).
  3. עוברים לשורה הבאה: `print(y - x)`, שמדפיסה את המספר `5` למסך.
  4. הפונקציה הסתיימה מבלי לפגוש שורת `return`. בפייתון, פונקציה שמסתיימת ללא `return` מחזירה אוטומטית את הערך המיוחד `None`!
  5. לכן `res` מקבל את הערך `None`, ובשורה האחרונה מודפס: `Result is: None`.
</details>

### שאלה 6: מילונים וספירה
מה יהיה הפלט בסיום הרצת הקוד הבא?
```python
d = {}
words = ["cat", "dog", "cat", "bird", "cat", "dog"]
for w in words:
    d[w] = d.get(w, 0) + 1

print(d["cat"] + d["bird"])
```

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

* **תשובה:** `4`
* **הסבר מפורט:**
  המילון סופר שכיחויות של כל מילה:
  * `"cat"` מופיעה 3 פעמים $\rightarrow$ `d["cat"] = 3`
  * `"dog"` מופיעה פעמיים $\rightarrow$ `d["dog"] = 2`
  * `"bird"` מופיעה פעם אחת $\rightarrow$ `d["bird"] = 1`
  לכן: `d["cat"] + d["bird"] = 3 + 1 = 4`.
</details>

### שאלה 7: תרגיל כתיבת קוד (בדיקת רשימה מסודרת)
כתבו פונקציה בשם `is_strictly_increasing(L)` המקבלת רשימת מספרים $L$ ומחזירה `True` אם הרשימה עולה ממש (כל איבר גדול בקפדנות מקודמו), ו-`False` אחרת.  
עבור רשימה ריקה או רשימה בעלת איבר אחד, יש להחזיר `True`.

דוגמאות:
* `is_strictly_increasing([1, 4, 8, 12])` $\rightarrow$ `True`
* `is_strictly_increasing([1, 4, 4, 9])` $\rightarrow$ `False` (כי 4 אינו גדול מ-4)
* `is_strictly_increasing([5, 3, 8])` $\rightarrow$ `False`

<details>
<summary><b>לחצו לצפייה בקוד הפתרון המלא</b></summary>

```python
def is_strictly_increasing(L):
    # עוברים על כל האיברים מאינדקס 0 עד האיבר הלפני-אחרון
    for i in range(len(L) - 1):
        # אם האיבר הנוכחי אינו קטן בקפדנות מהאיבר שמימינו:
        if L[i] >= L[i + 1]:
            return False  # מצאנו הפרה - אין צורך להמשיך לבדוק!
            
    # אם עברנו על כל הרשימה ולא נמצאה שום הפרה:
    return True

# בדיקות:
print(is_strictly_increasing([1, 4, 8, 12]))  # True
print(is_strictly_increasing([1, 4, 4, 9]))   # False
print(is_strictly_increasing([5, 3, 8]))      # False
print(is_strictly_increasing([42]))           # True
print(is_strictly_increasing([]))             # True
```
</details>
