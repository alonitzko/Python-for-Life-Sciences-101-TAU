## טבלת סיכום והשוואת מבני נתונים

| תכונה | מחרוזת (`str`) | רשימה (`list`) | מילון (`dict`) |
| :--- | :--- | :--- | :--- |
| **איברים** | תווים בלבד | כל טיפוס נתונים | זוגות מפתח-ערך |
| **סוגריים** | מרכאות `""` | מרובעים `[]` | מסולסלים `{}` |
| **גישה** | אינדקס מספרי `s[i]` | אינדקס מספרי `L[i]` | מפתח ייחודי `d[key]` |
| **שינוי במקום** | **לא** (Immutable) | **כן** (Mutable) | **כן** (Mutable) |
| **חיפוש (`in`)** | $O(n)$ | $O(n)$ | **$O(1)$ מיידי** לפי מפתח |

### שאלה 1 (מעקב מילון)
מה יודפס בסיום הקוד הבא?
```python
d = {"cat": 2, "dog": 3}
d["cat"] += 1
d["bird"] = d.get("bird", 0) + 5
print(d["cat"] + d["bird"])
```

<details>
<summary><b>לחצו לצפייה בפתרון המלא</b></summary>

**תשובה:** `8`  
**הסבר:**
* `d["cat"]` עודכן מ-2 ל-3.
* `d["bird"]` אותחל ל-5.
* $3 + 5 = 8$.
</details>
