## 1. מהי רשימה וכיצד מאתחלים אותה?

**רשימה (`list`)** היא אוסף סדור של איברים המוקפים בסוגריים מרובעים `[ ]`, כאשר האיברים מופרדים בפסיקים:

```python
primes = [2, 3, 5, 7, 11]
names = ["דנה", "יוסי", "רוני"]
mixed = [42, "שלום", 3.14, True]  # רשימה יכולה להכיל טיפוסים שונים!
empty_list = []                    # רשימה ריקה
```

* **הסדר חשוב:** שתי רשימות עם אותם איברים בסדר שונה אינן שוות (`[1, 2] != [2, 1]`).
* **אורך הרשימה:** נמדד באמצעות הפונקציה `len(L)`.

---

## 2. גישה לאיברים ואינדקסים

בדומה למחרוזות, האינדקסים מתחילים מ-**0** ומסתיימים ב-**`len(L) - 1`**:

```python
grades = [90, 85, 98, 72]

print("ציון ראשון:", grades[0])   # 90
print("ציון אחרון:", grades[-1])   # 72 (אינדקס שלילי)
```

---

## 3. ההבדל הקריטי: רשימה היא Mutable (ניתנת לשינוי)!

להבדיל ממחרוזת שבה אסור לשנות תווים במקום, ברשימה **ניתן לשנות, להחליף ולעדכן איברים ישירות**:

```python
colors = ["אדום", "ירוק", "כחול"]
colors[1] = "צהוב"  # החלפת האיבר באינדקס 1
print(colors)       # ['אדום', 'צהוב', 'כחול']
```

:::{important} Mutability (יכולת שינוי)
* **`str` (אינו ניתן לשינוי):** `s = "cat"; s[0] = "b"` $	o$ שגיאת `TypeError`!
* **`list` (ניתן לשינוי):** `L = ["c", "a", "t"]; L[0] = "b"` $	o$ תקין לחלוטין!
:::

## 4. שרשור ושכפול רשימות

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/alonitzkovitch/python_course_book/blob/main/practice/interactive_labs.ipynb)
[![Open In Kaggle](https://kaggle.com/static/../images/open-in-kaggle.svg)](https://kaggle.com/kernels/welcome?src=https://raw.githubusercontent.com/alonitzkovitch/python_course_book/main/practice/interactive_labs.ipynb)


```python
L1 = [1, 2, 3]
L2 = [4, 5]

# שרשור (+)
print("שרשור:", L1 + L2)  # [1, 2, 3, 4, 5]

# שכפול (*)
print("שכפול:", L2 * 3)   # [4, 5, 4, 5, 4, 5]

# בדיקת שייכות (in)
print("האם 2 ב-L1?", 2 in L1)    # True
print("האם 99 ב-L1?", 99 in L1)  # False
```

## ❓ שאלת הבנה

מה יודפס בסיום הקוד הבא?
```python
a = [10, 20, 30]
b = a
b[0] = 99
print(a[0])
```

<details>
<summary><b>לחצו לצפייה בתשובה והסבר</b></summary>

**תשובה:** `99`  
**הסבר:** השמה `b = a` אינה משכפלת את הרשימה, אלא גורמת לשני המשתנים להצביע על **אותה הרשימה בזיכרון** (Aliasing). שינוי דרך `b` משפיע ישירות גם על `a`!
</details>
