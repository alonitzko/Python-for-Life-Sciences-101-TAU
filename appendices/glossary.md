# מילון מונחים (Glossary) עברי - אנגלי

> ריכוז מונחי מפתח במדעי המחשב ובשפת פייתון שנלמדו לאורך הקורס, מלווים בהגדרות תמציתיות.

| מונח בעברית | מונח באנגלית | הגדרה תמציתית |
| :--- | :--- | :--- |
| **אלגוריתם** | Algorithm | סדרה סופית ומדויקת של צעדים ופקודות לפתרון בעיה חישובית נתונה. |
| **איטרציה** | Iteration | מחזור הרצה בודד של גוף לולאה (`for` או `while`). |
| **אינדקס** | Index | מספר המציין את מיקומו של איבר בתוך רצף (מחרוזת או רשימה). בפייתון מתחיל מ-0. |
| **ביט** | Bit (Binary Digit) | יחידת המידע הבסיסית ביותר במחשב, בעלת ערך של `0` או `1`. |
| **בייט** | Byte | מקבץ של 8 ביטים, המאפשר לייצג $2^8 = 256$ צירופים שונים (0 עד 255). |
| **ביט זוגיות** | Parity Bit | ביט בקרה שנוסף למסר כדי לוודא שסך האחדים הוא תמיד זוגי, לצורך גילוי שגיאות שידור. |
| **בקרת זרימה** | Control Flow | הסדר שבו פקודות הקוד מתבצעות, הנקבע באמצעות תנאים (`if`), לולאות ופונקציות. |
| **בעיית העצירה** | Halting Problem | הוכחתו של טיורינג שאין אלגוריתם המסוגל לקבוע עבור כל תוכנית וקלט האם תעצור או תרוץ לנצח. |
| **בעיית השידוך היציב** | Stable Matching | בעיה תורת-משחקית למציאת שידוך שבו אין זוג המעדיף זה את זו על פני בני זוגם (Gale-Shapley). |
| **גודל קלט** | Input Size ($n$) | כמות הנתונים המוזנת לאלגוריתם (למשל אורך רשימה או מספר ספרות). |
| **גווני אפור** | Grayscale | תמונה שבה כל פיקסל מקבל ערך בהירות בודד בין 0 (שחור) ל-255 (לבן). |
| **הדמיית נתונים** | Data Visualization | הצגה חזותית וגרפית של נתונים מספריים באמצעות תרשימים (כגון `matplotlib`). |
| **הזחה** | Indentation | הריווח בתחילת שורת קוד, הקובע בפייתון את השיוך של פקודות לבלוק מסוים (גוף תנאי, לולאה או פונקציה). |
| **השמה** | Assignment | פעולת הצבת ערך לתוך משתנה באמצעות הסימן `=`. |
| **השוואה לקסיקוגרפית** | Lexicographical | השוואה של מחרוזות לפי סדר הופעת התווים במילון (קוד ה-ASCII/Unicode שלהם). |
| **חיפוש בינארי** | Binary Search | אלגוריתם חיפוש בשיטת "הפרד ומשול" על רשימה ממוינת, בסיבוכיות $O(\log n)$. |
| **חיפוש סדרתי** | Linear Search | חיפוש איבר ע"י מעבר סדרתי על כל איברי הרשימה מתחילתה ועד סופה, בסיבוכיות $O(n)$. |
| **טיפוס נתונים** | Data Type | סיווג הערך (כגון `int`, `float`, `str`, `bool`, `list`, `dict`) הקובע אילו פעולות חוקיות עליו. |
| **לולאה** | Loop | מבנה תכנותי המבצע קטע קוד שוב ושוב עד להתקיימות תנאי עצירה. |
| **לולאה אינסופית** | Infinite Loop | באג שבו תנאי העצירה של הלולאה לעולם אינו מתקיים, והתוכנית נתקעת לנצח. |
| **מודולו** | Modulo (`%`) | אופרטור המחזיר את שארית החלוקה של מספר אחד במשנהו. |
| **מוטביליות** | Mutability | התכונה של מבנה נתונים המאפשרת לשנות את תוכנו במקום (כמו ברשימה או מילון, להבדיל ממחרוזת). |
| **מילון** | Dictionary (`dict`) | מבנה נתונים הממפה מפתחות ייחודיים לערכים (Key-Value) בגישה מהירה של $O(1)$. |
| **מיון בחירה** | Selection Sort | אלגוריתם מיון המוצא בכל שלב את המינימום ומוסיף אותו לסוף רשימה ממוינת, בסיבוכיות $O(n^2)$. |
| **מטריצה** | Matrix | רשת דו-ממדית של ערכים, המיוצגת בפייתון לרוב כרשימה מקוננת של רשימות. |
| **מרחק המינג** | Hamming Distance | מספר המיקומים שבהם שני רצפי ביטים באותו אורך שונים זה מזה. |
| **משתנה** | Variable | תא זיכרון בעל שם מזהה המאחסן ערך הניתן לקריאה ולשינוי. |
| **ניתוח תדירויות** | Frequency Analysis | שיטה לפענוח צפנים המבוססת על ספירת שכיחות הופעת האותיות והשוואתן לשפה הטבעית. |
| **סיבוכיות זמן** | Time Complexity ($O$) | הערכה מתמטית של קצב גידול זמן הריצה של אלגוריתם כפונקציה של גודל הקלט. |
| **ערך החזרה** | Return Value | הערך המועבר על ידי הפקודה `return` מגוף הפונקציה בחזרה לנקודת הקריאה. |
| **פונקציה** | Function | יחידת קוד עצמאית המקבלת קלטים (ארגומנטים), מבצעת חישוב ומחזירה פלט. |
| **פיקסל** | Pixel | יחידת התמונה הבסיסית ביותר (Picture Element) ברשת של תמונה דיגיטלית. |
| **פלינדרום** | Palindrome | מילה או משפט הנקראים זהה לחלוטין קדימה ואחורה. |
| **פסאודו-קוד** | Pseudocode | תיאור מילולי בלתי-פורמלי של אלגוריתם בשפה אנושית המיועד להבנת הרעיון החישובי. |
| **צופן הצבה** | Substitution Cipher | שיטת הצפנה שבה כל אות באלפבית מוחלפת באות קבועה אחרת מאלפבית מעורבב. |
| **צופן קיסר** | Caesar Cipher | צופן הצבה מחזורי שבו כל אות מוסטת במספר קבוע של צעדים קדימה. |
| **רשימה** | List (`list`) | אוסף סדור ובר-שינוי של איברים הנתונים בתוך סוגריים מרובעים. |
| **שגיאת תחביר** | SyntaxError | שגיאה המתרחשת כאשר הקוד מפר את כללי הדקדוק של שפת התכנות. |
| **שגיאת זמן ריצה** | RuntimeError | שגיאה המתרחשת בעת הרצת התוכנית כתוצאה מפעולה בלתי חוקית (כגון חלוקה באפס). |
| **שגיאה לוגית** | Logical Bug | טעות בהיגיון התוכנית הגורמת לה להפיק תוצאה שגויה על אף שהקוד רץ ללא קריסה. |
